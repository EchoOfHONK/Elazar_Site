# AYROHANT Dark Fantasy Manga Site

## Обновление оформления: 12 сентября 2026

Раздел манги временно скрыт из навигации и админки; переход на `reader.html` возвращает на главную. Файлы читалки и данные томов сохранены. Для возобновления уберите ограничение в `nav.js`, скрытие раздела `volumes` в `cinema.css` и фильтр новостей в `app.js`.

Некрономикон содержит каталоги персонажей и локаций. Нажатие карточки открывает статью по ссылке вида `wiki.html#characters/ID` или `wiki.html#locations/ID`. В админке у обеих категорий есть поля «Краткое описание» и «Полная статья»; абзацы полной статьи отделяются пустой строкой. Если статья ещё не заполнена, используется имеющееся описание, без выдуманного дополнения истории.

Карта на главной теперь встроена как интерактивная мини-карта. Кнопка в левом верхнем углу разворачивает её на весь экран; повторное нажатие или Escape возвращает компактный вид. Масштаб и выбранная локация сохраняются при разворачивании. В браузере без Fullscreen API отдельная карта раскрывается поверх страницы, а встроенная открывается отдельной вкладкой. Изображение и пины по-прежнему управляются существующим редактором админки. Если фон карты не загружен, показывается нейтральная координатная сетка.

Иконки Lucide хранятся локально в `public/assets/lucide.min.js`, лицензия рядом в `lucide-LICENSE.txt`. Проверки дизайна изолируют внешний Twitch-плеер; его внутренний JavaScript не входит в тесты сайта.

Новый кинематографичный дизайн подключён ко всем семи страницам через `public/cinema.css` после основного `styles.css`. Данные, API, авторизация и обработчики управления не менялись. Три темы, адаптивная навигация и существующий контент сохранены.

Перед изменениями создан полный ZIP-бэкап: `../dark-fantasy-manga-site-backup-20260912-172630.zip`. Он содержит сервер, страницы, README, контент и загруженные файлы. Для восстановления остановите сервер, распакуйте архив в отдельную папку и запускайте `server.js` из восстановленной папки. Не распаковывайте поверх рабочей версии без сохранения новых данных.

Новый фон: `public/assets/cinema-hero.png`, создан встроенным ImageGen. Промпт: кинематографичный широкоформатный тёмный фэнтези-кадр, средневековый страж у костра, разрушенный готический замок и кровавая луна; спокойные боковые области для текста, без надписей и рамок. Исходные изображения не заменены.

Проверка оформления: `design-check.cjs` (нужны Playwright и установленный Chrome). Укажите путь к модулю Playwright через `PLAYWRIGHT_MODULE`, запустите сайт и выполните `node design-check.cjs`. Скрипт проверяет страницы на 1440 и 390 px, меню, темы, вкладки, просмотр изображений, читалку, карту и соответствие текста текущему треку; снимки сохраняются в `design-check/`. Контент тест не изменяет.

Сайт-архив для манги и лора: главная страница, читалка, некрономикон, отдельная интерактивная карта, источники, темы оформления и админ-панель для редактирования контента.

## Что внутри

- `server.js` - Node.js сервер без внешних зависимостей.
- `data/content.json` - весь редактируемый контент сайта.
- `public/index.html` - главная страница.
- `public/reader.html` - читалка манги.
- `public/ballads.html` - баллады, плейлисты, треки и плеер.
- `public/wiki.html` - некрономикон: персонажи и локации.
- `public/map.html` - отдельная интерактивная карта.
- `public/admin.html` - админ-панель.
- `public/assets/` - изображения, фоны, аватарки и загруженные файлы.

## Быстрый запуск

Нужен Node.js 18+.

Windows PowerShell:

```powershell
cd "C:\Users\Surface Pro 7\Documents\ALL-SYSTEM\dark-fantasy-manga-site"
Copy-Item .env.example .env
# Откройте .env и задайте уникальные ADMIN_LOGIN и ADMIN_TOKEN.
node .\server.js
```

Linux/macOS:

```bash
cd dark-fantasy-manga-site
cp .env.example .env
# Откройте .env и задайте уникальные ADMIN_LOGIN и ADMIN_TOKEN.
node server.js
```

После запуска:

- сайт: `http://localhost:3000`
- читалка: `http://localhost:3000/reader.html`
- баллады: `http://localhost:3000/ballads.html`
- сказания: `http://localhost:3000/legends.html`
- некрономикон: `http://localhost:3000/wiki.html`
- карта: `http://localhost:3000/map.html`
- админка: `http://localhost:3000/admin.html`

## Доступ в админку

Логин и пароль задаются в локальном файле `.env`, который не попадает в Git. Скопируйте `.env.example` в `.env` и замените демонстрационные значения на свои. Переменные окружения системы имеют приоритет над файлом `.env`:

```powershell
$env:ADMIN_LOGIN="your-login"
$env:ADMIN_TOKEN="your-strong-password"
```

или:

```bash
ADMIN_LOGIN="your-login" ADMIN_TOKEN="your-strong-password" node server.js
```

## Как пользоваться админкой

1. Откройте `http://localhost:3000/admin.html`.
2. Введите логин и пароль.
3. Выберите раздел слева.
4. Отредактируйте нужный контент.
5. Нажмите `Сохранить всё`.

Разделы админки:

- `Основное` - название сайта, герой-блок, подвал.
- `Twitch` - ник канала для встроенного блока.
- `Новости` - карточки на главной.
- `Манга` - тома, главы, страницы и изображения страниц.
- `Баллады` - плейлисты, solo-треки, обложки, фоны, аудиофайлы и тексты.
- `Некрономикон: персонажи` - имя, роль, фракция, описание, аватарка.
- `Некрономикон: локации` - название, тип, описание, изображение и пины карты.
- `Соцсети` - внешние ссылки.

## Рекомендуемые размеры изображений

Эти размеры продублированы в админке над соответствующими блоками.

| Что загружаете | Размер | Формат | Где используется |
| --- | --- | --- | --- |
| Портрет персонажа | `900 x 1200 px` | вертикальный `3:4` | карточки персонажей и просмотр оригинала |
| Изображение локации | `640 x 640 px` | квадрат `1:1` | карточки локаций, панель карты, просмотр оригинала |
| Фон карты | `2400 x 1600 px` или больше | горизонтальный `3:2` | публичная карта и редактор пинов |
| Обложка плейлиста / трека | `1000 x 1000 px` | квадрат `1:1` | карусель баллад, список треков, нижний плеер |
| Фон плейлиста | `2400 x 1400 px` или больше | горизонтальный `12:7` | задний фон страницы баллад при выборе плейлиста |
| Страница манги | любой единый размер для главы | вертикальный или разворот | читалка манги |

Для портретов лучше держать лицо и силуэт ближе к центру. Для карты оставляйте важные места не у самого края, чтобы пины и масштабирование не выглядели тесно.

## Манга и читалка

Структура манги:

```text
Том -> Глава -> Страница
```

Для страниц можно:

- загрузить изображение через админку;
- указать URL картинки вручную;
- менять порядок страниц кнопками `Выше` / `Ниже`;
- оставить текстовый placeholder, если картинки пока нет.

Загруженные через админку файлы сохраняются в:

```text
public/assets/uploads/
```

## Некрономикон

Некрономикон живёт на:

```text
/wiki.html
```

Там два раздела:

- персонажи;
- локации.

Аватарки и изображения кликабельны: при клике открывается оригинал в крупном просмотре.

## Карта

Карта вынесена отдельно:

```text
/map.html
```

На публичной карте:

- пины кликабельны;
- справа показывается выбранная локация;
- ползунок меняет масштаб карты.

В админке карта редактируется в разделе `Некрономикон: локации`:

- фон карты загружается в поле `Загрузить фон карты`;
- двойной клик по карте добавляет новый пин;
- перетаскивание пина меняет координаты `X` и `Y`;
- список справа быстро выбирает нужную точку;
- удалить пин можно удалением соответствующей локации;
- точные координаты можно править руками в полях `X на карте, %` и `Y на карте, %`.

## Баллады

Баллады живут на отдельной странице:

```text
/ballads.html
```

На странице есть:

- карусель плейлистов со стрелками влево и вправо;
- отдельный фон у каждого плейлиста;
- автоматическая смена заднего фона страницы при выборе плейлиста;
- список треков внутри выбранного плейлиста;
- нижний аудиоплеер;
- боковая панель с текстом плейлиста или выбранного трека.

Solo-трек лучше заводить как обычный плейлист с одним треком и типом `solo`. Так он будет выглядеть и управляться так же, как остальные баллады.

В админке раздел `Баллады` позволяет:

- добавлять и удалять плейлисты;
- менять порядок плейлистов;
- загружать обложку плейлиста;
- загружать фон плейлиста;
- задавать акцентный цвет плейлиста;
- добавлять и удалять треки;
- менять порядок треков;
- загружать аудиофайл трека;
- загружать отдельную обложку трека;
- редактировать текст для боковой панели.

Поддерживаемые аудиоформаты:

```text
.mp3, .wav, .ogg, .m4a
```

Максимальный размер одного загружаемого файла сейчас `350 MB`. Если трек пока не загружен, кнопка воспроизведения откроет боковую панель с текстом, но аудио не запустится.

## Хроники и сказания

В `Новости` каждая карточка может содержать текст, ссылку и медиа: картинку или локальное видео. В админке укажите `Тип медиа` (`image` или `video`) и загрузите файл в поле «Загрузить картинку или видео». Для роликов используются `.mp4` и `.webm`.

`/legends.html` - видеораздел «Сказания». В админке он состоит из трёх уровней:

```text
Сказание -> Эпизод -> Главы и варианты качества
```

Для эпизода можно загрузить основной `.mp4`/`.webm`, добавить несколько вариантов качества (например, `720p` и `1080p`) и разметить главы. Начало каждой главы задаётся числом в секундах: `90` соответствует `1:30`. Плеер поддерживает запуск кнопкой или пробелом, звук, скорость, качество, переходы по главам, широкий и полноэкранный режимы. Сервер отдаёт видео с byte range-запросами, поэтому перемотка работает и для локальных файлов.

Рекомендуемые материалы для сказаний:

| Что загружаете | Рекомендуемый размер | Формат |
| --- | --- | --- |
| Обложка сказания | `1600 x 900 px` | `16:9`, jpg/png/webp |
| Видео эпизода | `1920 x 1080 px` | `.mp4` H.264/AAC или `.webm` |

## Деплой на сервер

Минимальный вариант:

```bash
git clone <repo-url>
cd dark-fantasy-manga-site
cp .env.example .env
# Задайте в .env уникальные ADMIN_LOGIN и ADMIN_TOKEN.
node server.js
```

Для постоянной работы удобно использовать `pm2`:

```bash
npm install -g pm2
PORT=3000 ADMIN_LOGIN="your-login" ADMIN_TOKEN="your-strong-password" pm2 start server.js --name ayrohant-site
pm2 save
pm2 startup
```

Для домена обычно ставят Nginx перед Node.js и проксируют запросы на `http://127.0.0.1:3000`.

Пример Nginx:

```nginx
server {
    server_name example.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## Обновление сайта

После изменения файлов:

```bash
pm2 restart ayrohant-site
```

Если запускаете вручную, остановите `node server.js` и запустите снова.

## Безопасность

- Не публикуйте файл `.env` и настоящие `ADMIN_LOGIN` и `ADMIN_TOKEN` в открытом репозитории.
- Для публичного сервера обязательно задайте свои значения переменных окружения.
- Делайте резервные копии `data/content.json`.
- Папку `public/assets/uploads/` тоже стоит бэкапить, потому что там лежат изображения, загруженные через админку.
